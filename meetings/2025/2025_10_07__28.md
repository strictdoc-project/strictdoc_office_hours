## Presentation of the 0.14.0 release

[https://github.com/strictdoc-project/strictdoc/releases/tag/0.14.0](https://github.com/strictdoc-project/strictdoc/releases/tag/0.14.0)
This release introduces a new feature: configuring StrictDoc using a Python file
instead of a TOML file, improvements to parsing SDoc nodes from source files,
the removal of the legacy Section/[SECTION] element, dropped Python 3.8 support.
