## Redirect server 

Idea: Sharing stable deep links to specific resources. Running a redirect server
to support redirecting a user coming with a stable deep link to a specific
requirements/documentation tool.

An example of a stable link to a requirement or other resources:

```
https://requirements.mycompany.com/?a=REQ-001
```

The redirect server maintains a registry that maps the available identifiers
to the underlying documentation/requirements tools.
