## PlantUML is now supported in StrictDoc

TL;DR: A user contributed a PR with PlantUML support, we integrated it, and PlantUML now works in a serverless mode in StrictDoc by default.

Release: https://github.com/strictdoc-project/strictdoc/releases/tag/0.29.0

Both Mermaid and PlantUML are enabled by default. The PlantUML implementation is
serverless, i.e., it does not require running a PlantUML server alongside
StrictDoc.
